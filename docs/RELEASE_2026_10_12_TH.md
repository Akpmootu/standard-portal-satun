# อัปเดต 12 ตุลาคม 2569: AI และ Telegram

เพิ่มหน้า /assistant และ /admin/integrations พร้อมการจำกัดสิทธิ์ โควตา AI และบันทึกการส่ง Telegram ที่กันส่งซ้ำ Apps Script รุ่น 6 เผยแพร่ที่ URL เดิมแล้ว ไม่มีการเพิ่มขอบเขต OAuth

ตรวจโค้ดและทดสอบ 155 รายการผ่าน การทดสอบนี้ไม่สร้างคำตอบ AI จริงและไม่ส่งข้อความไป Telegram

ตั้งค่ากุญแจบริการบนโฮสต์แบบลับแล้ว เปิด Telegram ตามคำอนุมัติของผู้ใช้: กลุ่ม SDHnoti ผ่าน @sdh_stn_bot สรุปรายวันตั้งเวลา 09:00 น. เวลาไทย (Hobby อาจเรียกช่วง 09:00–09:59 น.) รายสัปดาห์วันจันทร์ และแจ้งกิจกรรมที่อนุมัติ ส่งสรุปทดสอบจากเว็บออนไลน์สำเร็จ Telegram message ID 626 และอ่านประวัติ sent กลับจากชีตแล้ว ตรวจหน้า Vercel Cron Jobs พบ enabled และ /api/integrations/cron เวลา 0 2 * * * แต่ยังไม่อ้างว่ารอบอัตโนมัติในอนาคตส่งสำเร็จ

ยืนยัน Mistral ผ่านบัญชี dh.satun@gmail.com องค์กร SSJ: แผน Free, pay-as-you-go ยังไม่เปิด, ไม่มีวิธีชำระเงิน, auto recharge disabled กุญแจเดิมตรงกับรายการที่แสดงในบัญชี จึงไม่สร้างกุญแจใหม่ เปิด AI_ENABLED และ AI_FREE_CONFIRMED หลังตรวจนี้แล้ว แต่คำขอจริงสองครั้งยังตอบ HTTP 429 type rate_limited ไม่มีคำตอบ AI สำเร็จ ไม่เปิดบริการชำระเงินเพื่อแก้ปัญหา และไม่อ้างว่าโควตาฝั่งผู้ให้บริการพร้อมใช้งาน ดู docs/AI_TELEGRAM_TH.md
