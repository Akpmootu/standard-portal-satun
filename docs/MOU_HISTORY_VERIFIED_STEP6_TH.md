## หน้าประวัติใหม่

- GET /mou/history: หน้าผู้ดูแล เลือกหน่วยบริการ/ปี/ผลตรวจ พร้อมแบ่งหน้าละ 25 รายการ
- GET /api/admin/mou-history: ข้อมูลชุดเดียวกัน ตรวจสิทธิ์ผู้ดูแลก่อนอ่านตารางประเมินและประวัติ
- ลิงก์ประวัติรายข้อในหน้า MOU แสดงเฉพาะผู้ดูแล
- แยกสถานะในประวัติจากสถานะปัจจุบัน แสดงผู้ตรวจ legacy เป็นชื่อจากระบบเดิม ไม่จับคู่หรือเพิ่มสิทธิ์บัญชี
- ตรวจ parent/year/unit และไม่ส่งข้อความผิดพลาดจาก Google หรือข้อมูลลับออกหน้าเว็บ
- หน้าปัจจุบันยังอ่านอย่างเดียว ทุกคำขอเขียนถูกปฏิเสธ

## การทดสอบ

96 tests ผ่าน รวม HTTP auth, บัญชีถูกลดสิทธิ์, ข้ามหน่วยบริการ/ปี, การกรอง/แบ่งหน้า, XSS และข้อมูลเสีย; source/config checks ผ่าน

เจ้าของรีสตาร์ตแล้ว ตรวจหน้าเว็บใหม่กับ Google สดผ่านวันที่ 7 กันยายน 2026 เวลา 09:39–09:41 น.: ประวัติรวม 95 / approved 38 / rejected 57 / pending parents 16; เปลี่ยนหน้า 1 เป็น 2 จาก 4 หน้าได้; กรอง rejected ได้ 57 รายการ; เปิดประวัติจากข้อ 1.1 ของ 09625 ได้ empty state ถูกต้อง; เปลี่ยนเป็น 09604 ได้ประวัติ 32 รายการและ pending 16 ข้อ ตรวจ UI ด้วยข้อมูลสมมติที่หน้าจอ 390px แล้วไม่ล้นแนวนอน และคืนขนาดจอเดิมหลังตรวจ ไม่ต้อง restart ซ้ำสำหรับโค้ดชุดนี้

## ต่อไป: บันทึกและตรวจประเมิน

อ่านกติกาจาก api_mou_save.php และ api_admin_review.php ในสำเนาระบบเดิมแล้ว:

1. หน่วยบริการบันทึกผล/รายละเอียด/ลิงก์แล้วผลกลับ pending พร้อมล้างชื่อ/เวลา/หมายเหตุตรวจล่าสุด แต่เก็บประวัติตรวจเดิม
2. ผู้ดูแลในระบบเดิมบันทึกข้าม time/category locks ได้ และการแก้ผลโดยผู้ดูแลไม่ล้างสถานะตรวจ ต้องทดสอบรักษากติกานี้แยกจากผู้ใช้หน่วยบริการ
3. ส่งกลับแก้ไขต้องมีหมายเหตุ การตรวจต้องระบุผู้ตรวจ และเพิ่มประวัติพร้อมเปลี่ยนผลล่าสุด
4. ต้องทำ version conflict + idempotency + การเขียนผลและประวัติร่วมกันก่อนเปิดรับหลายคน การใส่ _version อย่างเดียวไม่ทำให้ Sheets มี compare-and-swap
5. owner token ที่แอปตั้งไว้ขอ spreadsheets.readonly / drive.metadata.readonly จึงยังเขียน/อัปโหลดไม่ได้ ต้องเตรียม write path และตรวจรับก่อนเพิ่ม scopes
6. การแจ้ง Telegram/ข้อความถึงผู้อื่นยังไม่ทำและไม่ได้รับอนุญาตจากคำสั่งพัฒนาระบบทั่วไป

การตรวจนี้ยืนยันความครบของ snapshot ที่นำเข้า ไม่ใช่การ sync ระบบ production แบบสด และยังไม่รวม CTAM/HAIT ปีอื่น หรือการตรวจสิทธิ์ลิงก์หลักฐาน
