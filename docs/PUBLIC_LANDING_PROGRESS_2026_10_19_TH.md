# Landing Page และกราฟภาพรวมสาธารณะ — 19 ตุลาคม 2569

หน้า `/` เป็น Landing Page สำหรับทุกคน รวมผู้ที่ลงชื่อเข้าใช้แล้ว อธิบายบทบาทระบบ MOU/CTAM/HAIT แสดงกราฟภาพรวม และขั้นตอนขอใช้งาน ส่วนบัญชีและเมนูงานเดิมอยู่ที่ `/account` และพื้นที่ทำงานอยู่ที่ `/overview`

## กราฟและข้อมูล

- API อ่านอย่างเดียว `/api/public/progress` ไม่ต้องลงชื่อเข้าใช้ แสดงเฉพาะยอดรวมระดับจังหวัด โมดูล จำนวนหน่วยบริการ จำนวนข้อ และเปอร์เซ็นต์ ไม่มีรายชื่อ รหัสหน่วยบริการ รายละเอียด ผู้รับผิดชอบ ความเห็น หรือหลักฐาน
- ใช้กติกาคำนวณเดียวกับรายงานภายใน MOU ใช้ปีงบประมาณปัจจุบัน CTAM/HAIT ใช้ชุดข้อมูลปัจจุบันที่ไม่แยกปี ไม่เปลี่ยนเกณฑ์ประเมินในงานนี้
- สลับ 3 มุมมอง: บันทึกผลแล้ว (ผ่าน/กำลังทำ/ไม่ผ่าน), ผ่านตามรายงาน และตรวจอนุมัติ ทั้งหมดหารด้วยจำนวนข้อในชุดรายงาน ไม่ใช่คะแนนรับรองมาตรฐาน
- อ่านใหม่ทุก 60 วินาทีเมื่อหน้าเปิดอยู่ พักเมื่อซ่อนแท็บ ปุ่มอ่านใหม่กดได้ มีเวลาอ่านต้นทางแสดงชัดเจน ใช้ cache สูงสุด 60 วินาทีต่อ instance และรวมคำขอที่มาพร้อมกัน CDN ใช้เฉพาะเวลาที่เหลือเพื่อไม่ยืดอายุ cache อีก 60 วินาที จึงเป็น polling ไม่ใช่ push ทุกครั้งที่มีผู้บันทึก
- ถ้าต้นทางล้มเหลว แสดงข้อมูลเดิมพร้อมคำเตือนและเวลาเดิม หากยังไม่เคยอ่านสำเร็จ แสดงข้อมูลไม่พร้อม ไม่ใช้ 0% แทนข้อผิดพลาด
- ไม่อ่านตารางบัญชีหรือสารบบระดับประเทศเพื่อทำกราฟ ใช้รายชื่อหน่วยบริการที่ระบบกำหนดใน mou_agencies และส่งออก DTO ที่เลือกเฉพาะตัวเลข

## การเข้าระบบ

Google Login ยืนยันตัวตนเท่านั้น ผู้ใช้ใหม่ต้องลงทะเบียน รอแอดมินอนุมัติบทบาทและหน่วยบริการ แล้วจึงบันทึก/ตรวจตามขอบเขตเดิม API รายละเอียดและ API เขียนยังต้องตรวจ session, สถานะบัญชี, scope, CSRF และรอบประเมิน ไม่สร้างบัญชีหรือเพิ่มสิทธิ์จากหน้า public

## ผลตรวจ

- ชุดทดสอบ 186 รายการผ่าน รวม projection ไม่ส่งข้อมูลส่วนบุคคล จำนวนและปีตรงกติการายงาน ปฏิเสธ query/POST บน summary การรวมคำขอ/cache/stale/failure และการป้องกัน API ส่วนตัวเดิม
- Chrome บน preview ที่เก็บข้อมูลสมมติในหน่วยความจำ: สลับกราฟผ่านตามรายงาน CTAM จาก 50% (บันทึก) เป็น 0% (ผ่าน) และอนุมัติ MOU 0%; บันทึกรายการสมมติอีกข้อแล้วหน้าเดิมอัปเดตจาก 25% / 1 ใน 4 เป็น 50% / 2 ใน 4 หลังหมด cache โดยไม่ reload หน้า
- ตรวจความกว้าง 320, 390, 768, 1025, 1440 px ไม่พบล้นแนวนอน
- อ่านข้อมูล Google จริงแบบไม่แก้ข้อมูล: MOU 74 หน่วยบริการ 2/2749 ข้อบันทึกและผ่าน; CTAM 7 โรงพยาบาล 102/119; HAIT 7 โรงพยาบาล 33/308 บันทึกและผ่าน ตรวจอนุมัติ 1/308 ตัวเลขเป็น snapshot ขณะตรวจ ไม่ใช่ค่าตายตัวในหน้าเว็บ
- ไม่แก้ผลประเมินหรือเพิ่มสิทธิ์บัญชีจริงเพื่อทดสอบกราฟ ไม่ส่ง Telegram

ขั้นต่อไป: ตรวจหน้า production หลัง deploy ว่าอ่านยอดจริงได้ทั้งผู้เยี่ยมชมและผู้ใช้ที่ลงชื่อเข้าใช้ แล้วให้ผู้ใช้งานตรวจรับข้อความและความเข้าใจของแต่ละเปอร์เซ็นต์
