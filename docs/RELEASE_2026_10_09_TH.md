## รุ่น CTAM / HAIT

- CTAM: 17 ข้อ 102 ผล 104 ประวัติจาก snapshot ต้นทางวันที่ 9 ตุลาคม 2569 อ่านกลับเทียบทุกเซลล์ผ่าน
- HAIT: 7 หมวด 44 ข้อ 34 ผลจาก snapshot วันเดียวกัน อ่านกลับเทียบทุกเซลล์ผ่าน ไม่พบประวัติตรวจ HAIT เป็นตารางแยกในต้นทาง จึงเพิ่มตาราง hait_review_history สำหรับผลตรวจใหม่
- คงสถานะ ผลประเมิน รายละเอียด ผู้รับผิดชอบ และหลักฐานเดิม การแก้โดยหน่วยบริการจะกลับ pending; การแก้โดยแอดมินคงผลตรวจเดิม
- บันทึกและตรวจผ่าน signed Apps Script writer version 3 พร้อม ScriptLock, version conflict, request receipt และ audit ใน batch เดียว
- สิทธิ์ reviewer ที่อนุมัติไว้เดิมยังเป็น MOU-only ไม่มีการขยายเป็น CTAM/HAIT โดยอัตโนมัติ; สองโมดูลนี้ให้แอดมินตรวจและให้โรงพยาบาลบันทึกของตนเอง
- เพิ่มหน้า CTAM / HAIT และสคริปต์ออกจากระบบที่ส่ง Origin/CSRF เดิมผ่าน same-origin fetch โดยคง form fallback
- MODULE_WRITES_ENABLED เป็น gate แยกก่อนเปิดบันทึก CTAM/HAIT
- ชุดทดสอบรวม 133 รายการผ่าน และตรวจ syntax ผ่านก่อนเผยแพร่

## รุ่นจัดการระบบและรายงาน

- แอดมินเปลี่ยนบทบาท/หน่วยบริการ/ขอบเขตผู้ตรวจและปิด–เปิดบัญชีได้ มีผลคำขอถัดไป อัปเดต account + identity + profile + audit + receipt พร้อมกัน ป้องกันปิดบัญชีตัวเองและแอดมินคนสุดท้าย
- เปิด–ปิดรอบ MOU ตาม setting เดิม มี version conflict และบันทึกผู้เปลี่ยน
- ประกาศภายในระบบแสดงแก่ผู้ได้รับอนุมัติ แอดมินเพิ่ม/แก้/ซ่อนได้ ไม่ส่งอีเมลหรือ LINE
- HAIT แสดงความเห็นและคำขอความช่วยเหลือรายหมวด ผู้ดูแลตอบได้ การแก้ความเห็นล้างคำตอบเดิมตามรอบใหม่
- การแจ้งเตือนผลตรวจ/ตอบความเห็นสร้างพร้อมผลตรวจใน batch เดียว ผู้รับอ่านได้เฉพาะของตัวเอง
- รายงาน MOU/CTAM/HAIT และ CSV อ่านเฉพาะหน่วยบริการ/ปีในสิทธิ์ ป้องกันสูตรอันตรายในไฟล์ CSV แยกสถานะหน่วยบริการกับผลตรวจ
- สำรวจ MOU ต้นทางทุกปีพบเฉพาะ 2569: 1,355 ผล + 95 ประวัติ นำเข้าเพิ่ม 2 ผลภายใต้ ScriptLock และเช็กเวอร์ชันผ่าน writer version 4 อ่านกลับทุกช่องตรงกัน ปลายทางรวม 1,356 ผลและ 96 ประวัติ (รวมรายการและประวัติจากระบบใหม่) ไม่พบไฟล์แนบต้นทาง
- GitHub เป็น repository ส่วนตัว พร้อม CI และเชื่อม Vercel

## ยังต้องทำก่อนย้ายทั้งระบบเสร็จ

- ทดสอบอัปโหลดและดาวน์โหลดผ่านเบราว์เซอร์ผู้ใช้จริงให้ครบ โดยการรับส่ง Drive และกู้ไฟล์จากข้อมูลสำรองผ่านแล้ว เครื่องมือเบราว์เซอร์ยังยืนยันไฟล์ดาวน์โหลดไม่ได้
- บัญชีเดิม 76 รายการและประวัติการแจ้งเตือนเดิม 369 รายการนำเข้าแท็บ archive ส่วนตัวครบ อ่านกลับเทียบทุกช่องแล้ว ยังต้องผูกบัญชีโดยตรวจยืนยันตัวจริงก่อนแสดงประวัติส่วนบุคคล (179 รายการอ้างรหัสผู้ใช้ที่ไม่พบในชุดบัญชีต้นทาง) ห้ามผูกจากอีเมลหรือชื่อเพียงอย่างเดียว
- ทวน delta ทุกโมดูลอีกครั้งในวันสลับระบบ เพราะระบบเดิมยังเปิดเขียนได้
- ผู้สมัครจริงทดสอบวงจรสมัคร–อนุมัติ–บันทึก–ตรวจ–แก้ไขบนออนไลน์
- ทดสอบหลายคนพร้อมกัน โควตา และการหมดอายุสิทธิ์เจ้าของ การสำรองเข้ารหัสและกู้คืนแยกทั้ง 25 ตาราง/ไฟล์ผ่านแล้ว ต้องจัดผู้รับผิดชอบและที่เก็บกุญแจแยกก่อนสลับจริง
- ระบบเดิมมี Mistral AI และ Telegram สรุปรายวัน/รายสัปดาห์/เตือนกำหนด ยังไม่ได้เชื่อมในระบบใหม่ ต้องยืนยันการใช้งาน ผู้รับ การส่งข้อมูล และเงื่อนไขงบประมาณก่อนเปิดบริการภายนอก กำหนด deadline ในสคริปต์เก่าเป็น 31 มกราคม 2568 จึงใช้ต่อโดยไม่ทวนไม่ได้
- ยืนยันทางเลือก hosting ที่เข้าเงื่อนไขงบประมาณของหน่วยงาน
- ตรวจรับและกำหนดวันสลับระบบพร้อมทางย้อนกลับ

ไม่มีการแก้ฐานข้อมูลต้นทางหรือให้สิทธิ์บัญชีจริงในรอบนำเข้า CTAM/HAIT ระบบเดิมยังต้องคงไว้จนตรวจรับครบ
