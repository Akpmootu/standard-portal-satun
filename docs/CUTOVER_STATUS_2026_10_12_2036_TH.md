## สิ่งที่ตรวจเพิ่มจริง

- การเชื่อมต่อเดิม timeout ก่อนเจ้าของเชื่อมเครือข่าย จากนั้นส่งออกแบบอ่านอย่างเดียวสำเร็จ ไม่แก้ฐานข้อมูลเก่า
- ตรวจ systemd timers ที่แสดงได้ พบชื่อ 19 รายการ ไม่พบชื่องานประเมินในรายการที่แสดง แต่ยังไม่ยืนยันว่าไม่มีงานใน root/user crontabs, drop-ins, container หรือ scheduler ภายนอก
- `/etc/nginx/sites-enabled/hait-status.conf` อ่านได้แต่เขียนไม่ได้; `/var/spool/cron/crontabs` อ่านไม่ได้จากบัญชี administrator ไม่เรียก sudo ซ้ำหรือข้ามข้อจำกัด
- เตรียม `ops/legacy-operator-preflight.php` ตรวจ syntax ด้วย PHP บนเซิร์ฟเวอร์แล้ว และรันแบบอ่านอย่างเดียวด้วยบัญชีปัจจุบัน ได้ runningAsRoot=false ไม่มีงานอ้างแอปในตำแหน่งที่อ่านได้ ผลนี้ไม่ใช่การตรวจ root สำเร็จ
- ตรวจจอมือถือ 18 หน้า (รวมภาพรวมที่เก็บแยก) และเดสก์ท็อป 7 หน้าหลัก รอบนี้เป็นการเปิดหน้า/อ่านข้อมูล/เมนู ไม่ได้กดบันทึกฟอร์มหรือทดสอบไฟล์ซ้ำ พบการวัดล้น 8px ช่วงเปลี่ยนหน้า MOU/dashboard/history; ตรวจ MOU/history หลังจัดวางเสร็จไม่พบส่วนล้น ต้องไม่ใช้ค่าชั่วคราวเป็นคำรับรองว่าตรวจ responsive ครบทุกกรณี
- คืนขนาดเบราว์เซอร์เดิมและเปิดหน้าบัญชี dh.satun@gmail.com ให้แล้ว ไม่มีการแก้ security ของ Chrome เพื่อเปิดหน้าที่ถูกบล็อก
