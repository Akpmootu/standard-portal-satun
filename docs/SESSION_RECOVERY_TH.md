# ขั้นที่ 3 — เซสชันหมดอายุและการบันทึกต่อ

วันที่ตรวจ: 26 ตุลาคม 2569

## พฤติกรรม

- ฟอร์ม MOU, CTAM, HAIT, สมัครใช้งาน, จัดการผู้ใช้, ไฟล์หลักฐาน และ integrations มีตัวช่วยเซสชันร่วมกัน
- เตือนล่วงหน้าประมาณ 2 นาที ก่อนเซสชัน 15 นาทีหมดอายุ และแนะนำเข้าสู่ระบบในแท็บใหม่ โดยไม่รีโหลดฟอร์มเดิม
- ข้อความและไฟล์ที่เลือกยังอยู่ในแท็บเดิม ไม่บันทึกร่างลง localStorage, sessionStorage หรือฐานข้อมูล ไม่ส่งบันทึกอัตโนมัติ
- ตรวจบัญชีเดิมก่อนส่งคำขอเขียน แล้วแทนเฉพาะ CSRF ใหม่ เก็บ requestId, expectedVersion และเนื้อหาคำขอเดิมไว้ ไม่ retry การเขียนอัตโนมัติ
- เตือนก่อนออกจากหน้าที่ยังมีการแก้ไข การอัปโหลดสำเร็จเพียงอย่างเดียวไม่ถือว่าบันทึกผลประเมินแล้ว
- หากคำขอแรกยังไม่ทราบผลและผู้ใช้แก้ข้อความเพิ่ม การยืนยันผลของคำขอเก่าจะไม่ล้างสถานะร่างของข้อความใหม่

## ขอบเขตความปลอดภัย

POST /api/session/recover ตรวจ Origin, เซสชันปัจจุบัน และบริบทฟอร์มเข้ารหัสที่มี issuer/audience แยกจาก session/upload ต้องตรง provider และ Google subject เดิม บริบทมีอายุ 8 ชั่วโมงและใช้แทนการล็อกอินไม่ได้ คืนเฉพาะ CSRF และเวลาหมดอายุ ไม่ต่ออายุ cookie ไม่คืน role ไม่อ่าน Google Sheets

การเขียนจริงยังตรวจบัญชี/สิทธิ์ปัจจุบัน CSRF และ expectedVersion ตามเดิม รวมถึงตรวจซ้ำใน Writer ไม่อนุญาตบัญชีที่ถูกปิดแม้กู้ CSRF สำเร็จ ไฟล์แนบยังตรวจ token และโควตาเดิม

## ผลตรวจ

- HTTP tests ใช้ codec จริงและนาฬิกาจำลอง: เซสชันหมดอายุ, เชื่อมบัญชีเดิม, บัญชีอื่น, ต่าง Origin, เพิ่ม field, token ปลอม/ผิด purpose/หมดอายุ และบัญชีถูกปิดก่อนเขียน
- Client tests: เก็บ requestId/version, ไม่ส่งคำขอเขียนเมื่อบัญชีผิด/หมดอายุ, รักษาร่างระหว่างคำขอที่ไม่ทราบผล, อัปโหลดไม่ล้างร่าง
- Codex Browser บน localhost และข้อมูลในหน่วยความจำ: กรอกร่างหลังหมดอายุ → ถูกปฏิเสธ → สลับบัญชีอื่นแล้วถูกปฏิเสธ → กลับบัญชีเดิม → บันทึกสำเร็จ พร้อมข้อความ/ลิงก์เดิม ไม่เขียนชีตจริง ไม่ส่ง Telegram
- ลิงก์ล็อกอินเปิดแท็บใหม่พร้อม noopener/noreferrer ไม่มี console error/warning ในหน้าจำลองที่ตรวจ
- ชุดทดสอบทั้งหมด 215 ผ่าน, source/config check ผ่าน และ build Writer ผ่าน ไม่มีการเปลี่ยน Apps Script ออนไลน์ในขั้นนี้

## ข้อจำกัด

ร่างอยู่เฉพาะเอกสารในแท็บ การปิดแท็บ รีโหลด เบราวเซอร์ล่ม หรือเครื่องดับอาจทำให้ข้อมูลสูญหาย ไม่ใช่ระบบสำรองร่างถาวร หากหน้าเปิดเกิน 8 ชั่วโมง ให้คัดลอกข้อความเก็บไว้ก่อนเปิดฟอร์มใหม่ ไฟล์ที่เลือกอาจต้องเลือกหรืออัปโหลดใหม่เมื่อ upload token เดิมหมดอายุ

การจำลองขนาดจอผ่าน capability รอบนี้ไม่เปลี่ยน innerWidth จึงไม่ใช้เป็นหลักฐานว่าตรวจครบทุก breakpoint หน้าที่สังเกตมี innerWidth 679px และ scrollWidth 664px ไม่มีการล้นแนวนอน ใช้ CSS flex-wrap และ breakpoint 480px สำหรับแถบแจ้งเตือน แต่ยังไม่รับรองทุกอุปกรณ์จากการตรวจนี้
