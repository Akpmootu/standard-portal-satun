# หลักฐาน PDF ผ่านลิงก์ Drive และรูปภาพ

นโยบายปัจจุบัน 12 ตุลาคม 2569 ตามคำขอผู้ใช้ ใช้กับ MOU, CTAM และ HAIT

## เอกสาร PDF

เก็บ PDF ใน Google Drive ที่หน่วยบริการดูแล แล้ววางลิงก์สำหรับเปิดไฟล์ในช่องลิงก์หลักฐาน ให้บัญชี Google ของผู้ตรวจมีสิทธิ์อ่านไฟล์ ไม่จำเป็นต้องตั้งไฟล์เป็นสาธารณะ ระบบเก็บเฉพาะ URL และไม่คัดลอก PDF เข้าพื้นที่ของระบบ ผู้ตรวจต้องเปิดตรวจเนื้อหาและสิทธิ์ของลิงก์ด้วยตนเอง ระบบไม่รับรองจาก URL อย่างเดียวว่าเป็น PDF หรือเปิดได้

ลิงก์หลักฐานเดิม เช่นเว็บไซต์หน่วยงานหรือหลักสูตรยังคงใช้ได้ ไม่เปลี่ยนผลประเมินเดิม การเว้นช่องลิงก์ว่างคงหลักฐานเดิมตามกติกาเดิม

## รูปภาพ

- อัปโหลด JPG/JPEG, PNG หรือ WebP ไม่เกิน 2 MiB (แสดงในหน้าเว็บเป็น 2 MB) หรือ 2,097,152 bytes ต่อไฟล์
- แนบ 1 รูปต่อรายการประเมิน ไม่รองรับ SVG, GIF, HTML หรือการอัปโหลด PDF ใหม่
- ตรวจนามสกุล ขนาด และลายเซ็นเนื้อหาที่ทั้งเบราว์เซอร์และเซิร์ฟเวอร์ ตรวจขนาดอีกครั้งใน Apps Script ก่อนจองไฟล์
- รูปเก็บเป็นไฟล์ส่วนตัวใน Drive ของระบบ ตรวจ SHA-256 และสิทธิ์ก่อนใช้งาน ไม่สร้างลิงก์สาธารณะ
- ต้องอัปโหลดสำเร็จแล้วกดบันทึกผลประเมิน จึงแนบเข้ารายการ การอัปโหลดอย่างเดียวไม่เปลี่ยนผลประเมิน
- ไม่ย่อรูปอัตโนมัติ หากเกินขนาดให้ลดขนาดรูปก่อนเลือกไฟล์ใหม่

ไฟล์ PDF ที่เคยอัปโหลดก่อนนโยบายนี้ยังดาวน์โหลดและตรวจหลักฐานเดิมได้ภายใต้สิทธิ์เดิม เพดาน 10 MiB ใช้เฉพาะไฟล์ PDF เดิม ไม่ใช่เพดานการอัปโหลดใหม่

## ตรวจสอบการเผยแพร่

Apps Script รุ่น 7 เผยแพร่ URL เดิม โดยไม่เพิ่มขอบเขต OAuth ทดสอบอัปโหลด PNG 68 bytes จริง ตรวจ checksum และดาวน์โหลดกลับผ่านบริการ Drive สำเร็จ อ่านผลประเมินก่อน/หลังตรงกัน ยังไม่แนบรูปทดสอบเข้ารายการจริง

การรับไฟล์ดาวน์โหลดผ่านเครื่องมือเบราว์เซอร์ยังเป็นรายการตรวจรับแยกจากการตรวจบริการ Drive สำเร็จ
