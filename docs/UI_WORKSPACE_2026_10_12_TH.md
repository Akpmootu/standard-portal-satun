# พื้นที่ทำงานรูปแบบร่วม — 12 ตุลาคม 2569

โครงหน้า เมนูหลัก เมนูมือถือ ตำแหน่งหน้าปัจจุบัน และทางกลับบัญชีใช้ `portal-layout.js` ร่วมกันในหน้าบัญชีที่อนุมัติแล้ว, MOU/ประวัติ/งานรอตรวจ/บันทึก, CTAM/HAIT/บันทึก, คำขอลงทะเบียน/อนุมัติ, ผู้ใช้/รอบประเมิน, รายงาน, คู่มือ, คลังข้อมูลเดิม, ประกาศ/แจ้งเตือน, ความช่วยเหลือ HAIT, หน้าบริการภายนอก และนโยบายข้อมูล

หน้าเข้าสู่ระบบสาธารณะยังคงรูปแบบแนะนำระบบและ Google Login ส่วนหน้า `/demo/*` เป็นหน้าจำลองเดิม ไม่ใช่พื้นที่ทำงานจริง

## พฤติกรรมสำคัญ

- `/overview` เพิ่มภาพรวม MOU/CTAM/HAIT ตามสิทธิ์ ใช้ตัวตรวจและการคำนวณรายงานเดิม ไม่อ่านผลนอกหน่วยบริการที่ได้รับอนุมัติ
- MOU เลือกปีได้; CTAM/HAIT แสดงข้อมูลปัจจุบันที่ต้นทางไม่ได้แยกปี จึงไม่สร้างตัวกรองปีที่ทำให้เข้าใจผิด
- แยกผลผ่านเกณฑ์ที่รายงานออกจากผลตรวจอนุมัติ ยอดรอตรวจในภาพรวมและรายงานไม่นับแถวสถานะ `none`
- ผู้ตรวจ MOU ไม่เห็นเมนู CTAM/HAIT และตัวเลือกโมดูลในรายงานไม่เสนอโมดูลที่ไม่มีสิทธิ์ ตัวตรวจฝั่งเซิร์ฟเวอร์ยังเป็นผู้บังคับสิทธิ์
- เมนู MOU เก็บหน่วยบริการและปีไว้เมื่อเปลี่ยนหน้าประเมิน/ประวัติ เมนูมือถือใช้ disclosure มาตรฐาน ไม่ต้องพึ่ง JavaScript
- มีลิงก์ข้ามไปเนื้อหาและกรอบโฟกัสสำหรับคีย์บอร์ด ตารางกว้างเลื่อนในกรอบตาราง
- ไม่นำผู้ช่วย Mistral ที่พักใช้งานมาเป็นเมนูหลัก แอดมินยังดูสถานะบริการได้

## การตรวจ

ชุดทดสอบทั้งหมด 170 รายการ รวมตรวจขอบเขตผู้ตรวจ การเก็บบริบทเมนู การป้องกัน HTML และการยกเลิกสิทธิ์หน้าภาพรวมทันทีหลังปิดบัญชีผ่าน HTTP ในเครื่อง รวมทั้งตรวจไวยากรณ์และรูปแบบไฟล์

ตรวจหน้าแสดงผลด้วยข้อมูลสมมติบนเบราว์เซอร์ทั้งขนาดมือถือและคอมพิวเตอร์ และตรวจเมนูมือถือเปลี่ยน CTAM → HAIT ก่อนเผยแพร่ ไม่มีการบันทึกผลประเมินจริงเพื่อทดสอบหน้าจอ

## งานตรวจรับถัดไป

การปรับหน้าจอไม่ได้แทนการตรวจวงจรจริงลงทะเบียน → อนุมัติ → บันทึกหลักฐาน → ส่งกลับ → ส่งใหม่ → อนุมัติ → ประวัติ/รายงาน ต้องเลือกรายการนำร่องและเนื้อหาจริงก่อนเขียนผล ไม่ใช้รายการที่อนุมัติแล้วเป็นข้อมูลทดลองโดยไม่ได้รับเลือก

หลังตรวจรับต้องกำหนดช่วงหยุดเขียนระบบเดิม กระทบยอดล่าสุด สำรองก่อน/หลัง และส่งมอบกุญแจสำรองแยกจากไฟล์สำรอง ระบบเดิมยังไม่ได้ปิดเขียนหรือประกาศให้เว็บใหม่เป็นแหล่งข้อมูลหลักในรอบนี้
